# StickS3 IMU Logger – Arduino version

`sticks3_imu_logger/` is the StickS3 IMU Logger firmware for the **Arduino IDE**: the same features, web page, CSV format and flash layout as the ESP-IDF build in the repository root. Recordings on a StickS3 are kept when you switch between the two.

## Files

| File | What it is |
| --- | --- |
| `sticks3_imu_logger.ino` | Entry point: `setup()` calls `app_run()`, which never returns |
| `app.h`, `main.cpp`, `imu.cpp`, `net.cpp`, `usb.cpp` | The firmware, **copied from `main/`** |
| `index_html.h` | The web page, **generated from `main/web/index.html`** |
| `partitions.csv` | Flash layout (copied); used because Partition Scheme is *Custom* |
| `sketch.yaml` | Board settings and pinned versions for arduino-cli |

The copied and generated files start with `GENERATED by tools/sync_arduino.py`. For changes that should go back into the repository, edit `main/` and run `python3 tools/sync_arduino.py` from the repository root. For your own experiments, edit the copies here freely.

## Set up the Arduino IDE (once)

1. **Boards Manager:** install **esp32** by Espressif Systems, version **3.3.x** (tested with 3.3.0).
2. **Library Manager:** install **M5Unified** version **0.3.0**; accept the offer to install **M5GFX** (0.3.0) with it.

## Build and upload

1. Open `sticks3_imu_logger/sticks3_imu_logger.ino`.
2. Set the **Tools** menu (there is no StickS3 entry in core 3.3.0, so a generic ESP32-S3 board is used):

| Setting | Value |
| --- | --- |
| Board | **ESP32S3 Dev Module** |
| USB CDC On Boot | Enabled |
| USB Mode | Hardware CDC and JTAG |
| CPU Frequency | 240MHz (WiFi) |
| Flash Size | 8MB (64Mb) |
| Partition Scheme | **Custom** |
| PSRAM | **OPI PSRAM** |
| Erase All Flash Before Sketch Upload | Disabled (enabling it deletes the recordings) |

3. Connect the StickS3 with a USB-C data cable, choose its port, click **Upload**.

The IDE may report a 16 MB maximum program size; that is a generic figure for the Custom scheme. The real limit is the 3 MB app partition; the firmware is about 1.2 MB.

## With arduino-cli

In the `sticks3_imu_logger` folder (settings come from `sketch.yaml`):

```bash
arduino-cli compile .
arduino-cli upload -p PORT .            # e.g. /dev/cu.usbmodem1101 or COM5
arduino-cli compile --profile sticks3 . # also pins the core and library versions
```

## Differences from the ESP-IDF build

| | ESP-IDF build | Arduino build |
| --- | --- | --- |
| ESP-IDF underneath | 6.1 | 5.5 (inside Arduino core 3.3) |
| Board settings | Fixed in `sdkconfig.defaults` | Tools menu (above) |
| Low-level settings | Editable (`idf.py menuconfig`) | Fixed by the core; what this firmware needs is already enabled |
| Web page | Embedded from `main/web/index.html` | Generated `index_html.h` |
| Boot log | ESP-IDF messages and `# ` status lines | `# ` status lines, plus a harmless `No core dump partition found` |

## If something is wrong

| You see | Cause |
| --- | --- |
| *No record buffer* when recording | PSRAM is not set to **OPI PSRAM** |
| *No storage*, recording off | Partition Scheme is not **Custom** |
| Recordings gone after upload | *Erase All Flash Before Sketch Upload* was enabled |
| Upload never connects | Download mode: hold the power button (next to USB-C) about 2 s until the green LED blinks, then upload again; afterwards double-press power to turn off and press once to turn on |
