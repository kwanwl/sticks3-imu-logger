StickS3 IMU Logger

Install or update the firmware on an M5Stack StickS3 from this page. Firmware version 2026-11-20.2.
  1. Use Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). Safari, Firefox, phones and iPads cannot do this.
  2. Connect the StickS3 with a USB-C data cable (not a charge-only cable). Close the Arduino IDE, serial monitors and other flashers.
  3. Click Install, choose the port named like USB JTAG/serial debug unit (macOS: cu.usbmodem…; Windows: COM…), then confirm.
  4. Wait until it reports success (about 30 s). The StickS3 restarts with the logger on page 1.
This browser cannot flash devices. Please use Chrome or Edge on a computer. Flashing needs a secure page (https).

Recordings saved on the StickS3 are kept: this installer never erases the flash.

If something goes wrong

ProblemWhat to do
No port appears, or it fails to connectPut the StickS3 in download mode: with USB connected, hold the power button (the small button next to the USB-C port) for about 2 s until the internal green LED blinks. Then click Install again.
Finished, but the screen stays blankIt is still in download mode: unplug the cable, double-press the power button to turn it off, then press it once to turn it on.
Still no portTry another USB-C cable (many only charge) or another USB port. On Linux, add your user to the dialout group and log in again.
The Install button is missingThe browser does not support Web Serial: use Chrome or Edge on a computer.

Other ways to install

  • Espressif's web flasher (any ESP32): open espressif.github.io/esptool-js, click Connect, add sticks3-imu-logger.bin at address 0x0, click Program. Do not press "Erase Flash" unless you want to delete the recordings.
  • From source with ESP-IDF or the Arduino IDE: see the repository README.

After installing

The StickS3 starts its own Wi-Fi hotspot, named like IMU-DA5734 (shown on page 1). Join it and open http://192.168.4.1 for live graphs and recordings. KEY2 (side button) changes page; KEY1 (blue button) zeroes, records and switches modes.

Wi-Fi busy? Use the same page over the USB cable instead: kwanwl.github.io/sticks3-imu-logger/usb (Chrome or Edge on a computer), then click Connect USB. Live graphs and downloading recordings work the same way.
